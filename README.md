# OOPS and C++ Concepts

This folder contains C++ practice programs and assignments completed during my Master's program, focused on strengthening Object-Oriented Programming (OOPS) and core C++ concepts.

Topics covered include:

- Standard Template Library (STL) functions
- Maps, vectors, and lists
- Pointers and double pointers
- Classes and objects
- Constructors and destructors
- Encapsulation and abstraction
- Header and source file organization
- File structure and modular programming
- Function overloading and basic polymorphism
- Memory handling and pointer-based operations

These assignments were developed as part of academic coursework and hands-on practice to improve problem-solving skills, code organization, and understanding of modern C++ programming principles.
